# ЛР №3 по веб-технологиям

**Вариант 8:** «Кулинар и фуд-блогер» — Flexbox-карточки блюд и Grid-галерея ингредиентов

## Требования
- Flexbox: горизонтальное адаптивное меню и карточки «Фирменные блюда» в ряд (1/2/3 колонки)
- Grid: галерея «Ингредиенты недели», сетка 3×2 на десктопе (1/2/3 колонки)
- Медиа-запросы для планшетов и мобильных, отсутствие горизонтальной прокрутки
- Контраст ≥ 4.5:1, семантические теги для карточек, пара «Время/ккал» через `<dl>`

## Реализация

### Flexbox: меню и карточки
Меню и карточки разложены флексом; количество колонок управляю через `flex-basis` карточек (`flex-wrap` не даёт странице растягиваться в ширину):

```css
.cards { display: flex; flex-wrap: wrap; gap: 24px; }
.card  { flex: 1 1 100%; }                                                        /* мобильный */
@media (min-width: 768px)  { .card { flex: 1 1 calc((100% - 24px) / 2); } }        /* 2 колонки */
@media (min-width: 1024px) { .card { flex: 1 1 calc((100% - 48px) / 3); } }        /* 3 колонки */
```

### Grid: «Ингредиенты недели»
Шесть ингредиентов дают ровно 3×2 на десктопе. Колонки через `minmax(0, 1fr)`, чтобы контент не распирал сетку:

```css
.ingredients-grid { display: grid; grid-template-columns: minmax(0, 1fr); gap: 24px; }
@media (min-width: 768px)  { .ingredients-grid { grid-template-columns: repeat(2, minmax(0, 1fr)); } }
@media (min-width: 1024px) { .ingredients-grid { grid-template-columns: repeat(3, minmax(0, 1fr)); } }
```

### Семантика и dl
Каждое блюдо — `<article>` внутри `<section>`, меню в `<nav>`, боковой блок — `<aside>`. Пары из варианта сделал списком определений (обёртка `<div>` внутри `<dl>` допустима в HTML5 и удобна для стиля «пилюль»):

```html
<dl class="dish-meta">
  <div class="meta-item"><dt>Время</dt><dd>45 мин</dd></div>
  <div class="meta-item"><dt>Ккал</dt><dd>320</dd></div>
</dl>
```

### Доступность и отсутствие прокрутки
- Контраст: текст `#332A25` на кремовом `#FDFBF7` (~13:1), белый на терракотовом `#B84A35` (~5.2:1) — выше требуемых 4.5:1
- Горизонтальной прокрутки нет: изображения с `max-width: 100%`, колонки Grid через `minmax(0, 1fr)`, меню и карточки переносятся
- Мелочи: skip-link, видимый `:focus-visible`, `alt` у всех фото

## Как проверить
DevTools (F12) → эмуляция устройства: 375 px — 1 колонка, 768 px — 2, 1024 px+ — карточки в 3 колонки и ингредиенты сеткой 3×2. Прокрутки по горизонтали нет ни на одной ширине.
